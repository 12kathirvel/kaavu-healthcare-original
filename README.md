## AI Assistant UI update
The `/assistant` page now uses a ChatGPT-style composer with a `+` attachment menu. It includes browser voice input, optional voice output, photo/document attachment previews, responsive mobile behavior, accessible labels/focus states, and reduced-motion support. Attachment metadata is passed to the NVIDIA chat route; file contents are not sent to the model yet.

UI/UX direction follows the public UI UX Pro Max guidance: hierarchy-first layout, Lucide icons, responsive/reflow-safe controls, visible focus states, restrained motion, and healthcare-appropriate visual language.
Reference: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill
